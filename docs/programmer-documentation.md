# AFMLabel - programmer documentation

**Document purpose:** guide for developers who build, test, maintain or extend AFMLabel: repository layout, environment, conventions, checks, extension points, CLI reference and representative source code excerpts.
**Software version:** AFMLabel 1.0.0

The architecture, data model and algorithms are described in the [technical documentation](technical-documentation.md); this document focuses on working with the code. Paths are relative to the repository root.

## 3. Build and install

AFMLabel is a pure-Python package built with **hatchling** (`[build-system]` in `pyproject.toml`). The version is read from `src/afmlabel/__init__.py` (`[tool.hatch.version]`); the wheel target packages `src/afmlabel` (Python modules, templates and static assets). There is no frontend build step: ES modules and CSS are served as they are, with content-hashed URLs generated by `templating.py`.

```bash
pip install -e ".[dev]"            # editable development install
python -m pip wheel . -w dist      # build a wheel (hatchling)
pip install dist/afmlabel-1.0.0-py3-none-any.whl
```

The console script `afmlabel` is declared in `[project.scripts]` (`afmlabel.main:cli`).

## 4. Coding conventions

- **Formatting and lint:** ruff with `line-length = 100`, `target-version = "py312"`, rule sets `E`, `F`, `I` (import order), `UP` (pyupgrade), `B` (bugbear); `B008` is ignored for FastAPI's `Depends`/`Query` defaults.
- **Types:** every function is annotated; mypy runs with `disallow_untyped_defs`, `no_implicit_optional`, `warn_unused_ignores` and `warn_redundant_casts`; missing stubs are ignored only for `uvicorn`, `torch`, `torchvision`, `huggingface_hub`, `tifffile`.
- **Licence headers:** every source file (Python, JS, CSS, HTML templates, shell and PowerShell scripts, YAML) starts with two comment lines, `SPDX-License-Identifier: MIT` and the copyright line from [`LICENSE`](../LICENSE), in the comment syntax of the file type (after a shebang or doctype). The exact text is defined in `scripts/add_license_headers.py` (`SPDX`, `COPYRIGHT`); `python scripts/add_license_headers.py` adds missing headers; `--check` and `tests/unit/test_license_headers.py` enforce them.
- **Models and persistence:** persisted documents are Pydantic models with `schema_version`; they are written only through `persistence.atomic.save_model` / `atomic_write_*`; paths only through `persistence.paths`.
- **Errors:** raise `afmlabel.errors.AppError` (or a subclass) with a code from `ERROR_CODES`, an HTTP status, an optional `target` and a `recovery` hint; the API turns it into the error envelope.
- **Mutations:** go through `ProjectStore.mutate_project`, `DatasetStore.mutate` or `RegionService.mutate` so that the revision check, atomic write and audit event happen in one place.
- **Frontend:** plain ES modules, no frameworks and no external assets; every state-changing request goes through `static/js/api.js` (adds `X-Requested-With: AFMLabel`); every control has a `data-help` key present in `static/help/registry.json` (checked by `tests/unit/test_help.py`).
- **No GUI toolkit dependency:** `tests/unit/test_no_qt.py` fails if Qt is declared, installed or imported.
- **Tests write only below `tmp/`** (`--basetemp=tmp/pytest`); never run two pytest sessions of one checkout at the same time.

## 6. Extension points

### 6.1 Adding a segmentation backend

1. Create `src/afmlabel/segmentation/<name>.py` with a class implementing the `SegmentationBackend` protocol (excerpt 8): `backend_id`, `descriptor()`, `segment(image, *, points, box_xyxy, previous_mask, text_prompt)`, `release()`; for real models also `load()` and `unavailable_reason()` so that the registry can report `not_loaded` / `failed` / `unavailable` and load in the background. Never import heavy libraries at module import time; import them in `load()`.
2. Call `validate_prompts_against_capabilities()` at the start of `segment()`, raise `BackendUnavailableError` when not loaded and `BackendOutOfMemoryError` on memory exhaustion; return boolean masks of exactly the image's height and width.
3. Add a settings model to `settings.ModelsSettings` (pin `revision` and `code_revision`; moving references are rejected by the validator) and a block in `config/app.example.yaml`.
4. Register the backend in `segmentation.registry.build_registry()`; the API (`/api/v1/models`), the backend picker and the capability-driven UI controls pick it up automatically.
5. Test it with the shared contract: `tests/model_contract/backend_contract.run_full_contract(backend)` (descriptor, typed errors, point/box/mask prompts, text rejection when unsupported, empty prompt rejection, determinism, idempotent release) and `afmlabel.diagnostics.models.run_backend_diagnostic(backend)`. Mark tests that need checkpoints with `@pytest.mark.real_model` (and `gpu` where applicable). If the backend needs a checkpoint, extend `scripts/download_models.py` so that it writes a `manifest.json` with SHA-256 for every file.

### 6.2 Adding an export profile

1. Implement the `ExportProfile` protocol from `exports/base.py`: attributes `profile_id`, `display_name` (and optionally `loader_id_matching`), and `write(root, context, datasets) -> list[DatasetExportEntry]`. Each `ExactDataset` already contains the validated, gated `label_map`, `instance_map`, instance table, export stem, region set and validation report; a profile only *transforms* this representation into files under `root` and must never touch project state.
2. Use `exports/rasters.write_label_raster` (lossless `uint16`), `write_color_mask` and `exports/native_exact.entry_for` to describe the written files so that the common manifest stays complete.
3. Register an instance in `PROFILES` in `exports/service.py`; `GET /api/v1/projects/{id}/exports/profiles` and the export dialog list it, and `export.default_profile` can select it.
4. Add an integration test that validates a dataset, exports with the new profile and checks the package content (see `tests/integration/test_exports_api.py`).

### 6.3 Adding an importer

Follow the two-step pattern of `imports/tswat.py` and `imports/lossy.py`:

1. **Stage:** store the upload under `workspace/tmp/uploads/<kind>/`, parse it, refuse dimension mismatches (never resample) and return a preview (matches, value or label mapping proposals, problems); nothing is written to the project.
2. **Commit:** create regions through `RegionService.create_regions()` (one revisioned transaction, one undo step) with a dedicated `Region.source` value and provenance containing at least the original filename, SHA-256, dimensions, mapping and importer version. New source values must be added to `RegionSource` (`domain/region.py`) and `EventSource` (`domain/events.py`).
3. Never decide scientific precedence: overlaps start `unreviewed`; lossy inputs must produce validation warnings (see `validation/engine.py`).
4. Add routes in `api/imports.py`, a dialog in `static/js/legacy-import.js` with `data-help` keys, and unit, integration and browser tests.

### 6.4 Other extension points

- **Schema change:** bump the constant in `domain/common.py`, register a step with `@register_step(kind, from_version)` in `persistence/migrations.py`, add a fixture of the old version under `tests/fixtures/` and a test in `tests/unit/test_migrations_compat.py`.
- **Validation rule:** add the check to `validation/engine.validate()` with an existing or new error code (`errors.ERROR_CODES`); `validation/findings.py` maps issues to Findings.
- **Keyboard shortcut or help text:** edit `static/help/shortcuts.json` or `registry.json`, then run `python scripts/generate_help_reference.py` to regenerate the table in `docs/user-guide.md`.
- **Configuration key:** add a field to the matching section model in `settings.py` (unknown keys are rejected), document it in `config/app.example.yaml`.

### Excerpt 2 - atomic writes

Every authoritative JSON file is written to a temporary file in the same directory and moved into place with `os.replace`, so readers see either the old or the new complete file. The retry helper handles transient Windows sharing violations.

`src/afmlabel/persistence/atomic.py`, lines 80-116:

```python
def atomic_write_bytes(path: Path, data: bytes, *, fsync: bool = True) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    fd, tmp_name = tempfile.mkstemp(dir=path.parent, prefix=f".{path.name}.", suffix=TEMP_SUFFIX)
    try:
        with os.fdopen(fd, "wb") as handle:
            handle.write(data)
            handle.flush()
            if fsync:
                os.fsync(handle.fileno())
        _replace_with_retry(tmp_name, path)
    except BaseException:
        with contextlib.suppress(OSError):
            os.unlink(tmp_name)
        raise


def atomic_write_text(path: Path, text: str, *, fsync: bool = True) -> None:
    atomic_write_bytes(path, text.encode("utf-8"), fsync=fsync)


def atomic_write_json(path: Path, data: dict[str, Any], *, fsync: bool = True) -> None:
    atomic_write_text(path, json.dumps(data, indent=2), fsync=fsync)


def save_model(path: Path, model: BaseModel, *, fsync: bool = True) -> None:
    atomic_write_text(path, model.model_dump_json(indent=2), fsync=fsync)


def load_json(path: Path) -> dict[str, Any]:
    data = json.loads(_read_text_with_retry(path))
    if not isinstance(data, dict):
        raise ValueError(f"{path}: expected a JSON object")
    return data


def load_model[T: BaseModel](path: Path, model_cls: type[T]) -> T:
    return model_cls.model_validate_json(_read_text_with_retry(path))
```

### Excerpt 3 - revisioned project mutation with audit event

The single read-modify-write path for projects: optimistic revision check under a per-project lock, mutation, uniqueness check of the class ontology, atomic writes (classes before project), audit event.

`src/afmlabel/projects/store.py`, lines 246-284:

```python
    def mutate_project(
        self,
        project_id: str,
        expected_revision: int,
        mutate: Callable[[Project, ClassOntology], None],
        *,
        operation: str,
        actor: str | None = None,
        source: EventSource = "manual",
        class_ids: list[int] | None = None,
        details: dict[str, Any] | None = None,
    ) -> tuple[Project, ClassOntology]:
        """Read-modify-write with optimistic revision check and audit event."""
        pdir = self.project_dir(project_id)
        with self._guard(project_id):
            project = self._load_project(pdir)
            if project.revision != expected_revision:
                raise RevisionConflictError(
                    {"project_id": project_id}, expected_revision, project.revision
                )
            ontology = self._load_ontology(pdir)
            mutate(project, ontology)
            ontology.validate_unique()
            previous = project.revision
            project.revision = previous + 1
            project.modified_at = utc_now_iso()
            save_model(paths.classes_file(pdir), ontology, fsync=self._fsync)
            save_model(paths.project_file(pdir), project, fsync=self._fsync)
        self.record_event(
            project_id,
            operation=operation,
            previous_revision=previous,
            new_revision=project.revision,
            actor=actor,
            source=source,
            class_ids=class_ids or [],
            details=details or {},
        )
        return project, ontology
```

### Excerpt 4 - mask input and rasterisation

Masks arrive as row run lengths, COCO RLE or polygons and are always converted on the server to a boolean array of exactly the dataset's size; polygons are rasterised by Pillow on the server, so the server defines pixel membership.

`src/afmlabel/api/regions.py`, lines 30-64:

```python
class MaskPayload(BaseModel):
    """Either row-major run lengths, COCO RLE or a polygon (image pixels)."""

    format: Literal["rle_rows", "coco_rle", "polygon"]
    size: list[int] | None = None
    counts: list[int] | str | None = None
    points: list[list[float]] | None = None

    def to_array(self, dataset: Dataset) -> np.ndarray:
        height, width = dataset.height, dataset.width
        if self.format == "polygon":
            if not self.points:
                raise AppError("VALIDATION_ERROR", "polygon needs points", status_code=422)
            try:
                return polygon_to_mask([(p[0], p[1]) for p in self.points], height, width)
            except ValueError as exc:
                raise AppError("VALIDATION_ERROR", str(exc), status_code=422) from exc
        if self.size is not None and list(self.size) != [height, width]:
            raise AppError(
                "VALIDATION_ERROR",
                f"mask size {self.size} does not match dataset [{height}, {width}]",
                status_code=422,
            )
        if self.format == "rle_rows":
            if not isinstance(self.counts, list):
                raise AppError("VALIDATION_ERROR", "rle_rows needs integer counts", status_code=422)
            try:
                return decode_rows(self.counts, height, width)
            except ValueError as exc:
                raise AppError("VALIDATION_ERROR", str(exc), status_code=422) from exc
        if not isinstance(self.counts, str):
            raise AppError("VALIDATION_ERROR", "coco_rle needs string counts", status_code=422)
        from afmlabel.domain.region import RleMask

        return decode_coco(RleMask(size=[height, width], counts=self.counts))
```

### Excerpt 5 - composition and overlap group identity

The core of the one-class-per-pixel rule: regions are painted in ascending z-order, so the highest z-order wins; the overlap group id depends on participants and the exact pixel set.

`src/afmlabel/overlaps/engine.py`, lines 85-115:

```python
def composable_regions(region_set: RegionSet, ontology: ClassOntology) -> list[Region]:
    enabled = {c.class_id for c in ontology.classes if c.enabled}
    return [r for r in region_set.sorted_by_z() if r.visible and r.class_id in enabled]


def compose(region_set: RegionSet, ontology: ClassOntology, height: int, width: int) -> Composition:
    label_map = np.zeros((height, width), dtype=np.int32)
    winner_map = np.zeros((height, width), dtype=np.int32)
    multiplicity = np.zeros((height, width), dtype=np.uint16)
    decoded: list[DecodedRegion] = []
    for index, region in enumerate(composable_regions(region_set, ontology), start=1):
        mask = decode_coco(region.coverage_rle)
        if mask.shape != (height, width):
            raise ValueError(
                f"region {region.region_id} mask {mask.shape} does not match {(height, width)}"
            )
        decoded.append(DecodedRegion(region=region, mask=mask))
        # Ascending z-order: later (higher) regions overwrite earlier ones.
        label_map[mask] = region.class_id
        winner_map[mask] = index
        multiplicity[mask] += 1
    return Composition(
        label_map=label_map, winner_map=winner_map, multiplicity=multiplicity, regions=decoded
    )


def _group_digest(region_ids: list[str], pixels: np.ndarray) -> str:
    digest = hashlib.sha256()
    digest.update(",".join(sorted(region_ids)).encode("utf-8"))
    digest.update(np.packbits(pixels.ravel()).tobytes())
    return f"ovl_{digest.hexdigest()[:12]}"
```

### Excerpt 7 - export gate

A dataset is exported only if its stored report is valid, belongs to the current revision and still matches the recomposed label map bit for bit; otherwise it is skipped with a machine-readable reason.

`src/afmlabel/exports/service.py`, lines 145-191:

```python
    def _exact(
        self, project_id: str, dataset_id: str, ontology: ClassOntology, options: ExportOptions
    ) -> tuple[ExactDataset | None, SkippedDataset | None]:
        dataset, region_set = self._regions.load(project_id, dataset_id)
        report = self._validation.latest_report(project_id, dataset_id)
        if report is None:
            return None, SkippedDataset(
                dataset_id=dataset_id,
                dataset_name=dataset.name,
                code="VALIDATION_MISSING",
                reason="dataset has never been validated",
            )
        if (
            report.dataset_revision != dataset.revision
            or dataset.validated_revision != dataset.revision
        ):
            return None, SkippedDataset(
                dataset_id=dataset_id,
                dataset_name=dataset.name,
                code="VALIDATION_STALE",
                reason=(
                    f"validated at r{report.dataset_revision}, dataset is at r{dataset.revision}"
                ),
            )
        if report.status != "valid":
            return None, SkippedDataset(
                dataset_id=dataset_id,
                dataset_name=dataset.name,
                code="VALIDATION_FAILED",
                reason="latest validation is blocked: "
                + ", ".join(i.code for i in report.blocking),
            )
        composition = compose(region_set, ontology, dataset.height, dataset.width)
        if composition.sha256() != report.composition_sha256:
            return None, SkippedDataset(
                dataset_id=dataset_id,
                dataset_name=dataset.name,
                code="VALIDATION_STALE",
                reason="composition differs from the validated one; validate again",
            )
        if (composition.label_map == 0).any():
            return None, SkippedDataset(
                dataset_id=dataset_id,
                dataset_name=dataset.name,
                code="UNLABELED_PIXELS",
                reason="composition contains unlabeled pixels",
            )
```

```python
def validate_prompts_against_capabilities(
    descriptor: BackendDescriptor,
    *,
    points: list[PointPrompt],
    box_xyxy: tuple[float, float, float, float] | None,
    previous_mask: np.ndarray | None,
    text_prompt: str | None,
) -> None:
    """Shared capability gate every backend can call before inference."""
    capabilities = descriptor.capabilities
    backend_id = descriptor.backend_id
    if points and BackendCapability.POINT_PROMPTS not in capabilities:
        raise BackendCapabilityError(
            backend_id, BackendCapability.POINT_PROMPTS, "point prompts are not supported"
        )
    if box_xyxy is not None and BackendCapability.BOX_PROMPTS not in capabilities:
        raise BackendCapabilityError(
            backend_id, BackendCapability.BOX_PROMPTS, "box prompts are not supported"
        )
    if previous_mask is not None and BackendCapability.MASK_PROMPTS not in capabilities:
        raise BackendCapabilityError(
            backend_id, BackendCapability.MASK_PROMPTS, "mask prompts are not supported"
        )
    if text_prompt is not None and BackendCapability.TEXT_PROMPTS not in capabilities:
        raise BackendCapabilityError(
            backend_id, BackendCapability.TEXT_PROMPTS, "text prompts are not supported"
        )
    if not points and box_xyxy is None and previous_mask is None and text_prompt is None:
        raise ValueError("at least one prompt (point, box, mask or text) is required")
```

### Excerpt 10 - authentication and CSRF middleware

Every non-public request needs a session; every state-changing API request needs the custom header and a same-origin indication.

`src/afmlabel/auth/middleware.py`, lines 66-124:

```python
def csrf_violation(request: Request) -> str | None:
    if request.method not in UNSAFE_METHODS:
        return None
    if request.headers.get(CSRF_HEADER) != CSRF_HEADER_VALUE:
        return f"missing {CSRF_HEADER} header"
    if not _same_origin(request):
        return "cross-origin request rejected"
    return None


def _error_json(error: AppError) -> JSONResponse:
    return JSONResponse(status_code=error.status_code, content=error.to_payload())


class AuthMiddleware(BaseHTTPMiddleware):
    def __init__(self, app: Any, *, sessions: SessionStore, accounts: AccountStore) -> None:
        super().__init__(app)
        self._sessions = sessions
        self._accounts = accounts

    async def dispatch(
        self, request: Request, call_next: Callable[[Request], Awaitable[Response]]
    ) -> Response:
        path = request.url.path
        is_api = path.startswith("/api/")
        session = self._sessions.resolve(request.cookies.get(SESSION_COOKIE_NAME))
        request.state.session = session

        if is_api:
            violation = csrf_violation(request)
            if violation is not None:
                return _error_json(
                    AppError(
                        "CSRF_REJECTED",
                        violation,
                        status_code=403,
                        recovery="send requests from the AFMLabel UI with the "
                        "X-Requested-With: AFMLabel header",
                    )
                )

        if _is_public(path) or session is not None:
            return await call_next(request)

        if is_api:
            return _error_json(
                AppError(
                    "AUTH_REQUIRED",
                    "authentication required",
                    status_code=401,
                    recovery="log in at /login",
                )
            )
        if not self._accounts.is_configured():
            return RedirectResponse("/setup", status_code=303)
        target = request.url.path
        if request.url.query:
            target += "?" + request.url.query
        return RedirectResponse(f"/login?next={quote(target, safe='')}", status_code=303)
```

## 8. CLI reference

### `afmlabel`

| Command | Options | Description |
| --- | --- | --- |
| `afmlabel serve` | `--host HOST` (default from config, `127.0.0.1`), `--port PORT` (default from config, `9080`), `--config PATH` | Create the application and run it with Uvicorn. |
| `afmlabel version` | - | Print the installed version. |
| `afmlabel auth set-password` | `--username NAME` (default `afmlabel`), `--config PATH` | Create the single account or change its password; prompts twice on a terminal, otherwise reads `AFMLABEL_PASSWORD`; revokes all sessions. Exit `2` on mismatch, weak password or missing terminal/variable. |
| `afmlabel auth status` | `--config PATH` | Show username, hash algorithm, last update and number of active sessions; exit `1` if no account exists. |
| `afmlabel auth revoke-sessions` | `--config PATH` | Log out every browser session. |

The configuration file can also be selected with `AFMLABEL_CONFIG_FILE`; every setting can be overridden with `AFMLABEL_<SECTION>__<KEY>`.
