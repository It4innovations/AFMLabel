Account setup required

AFMLabel supports exactly one user account and it has not been created yet. Accounts are created on the server, never through the browser. Run, inside the application virtual environment: 

afmlabel auth set-password --username <name>

The command prompts for the password (or reads AFMLABEL_PASSWORD from the environment) and stores only an Argon2id hash under the workspace. Reload this page afterwards.
